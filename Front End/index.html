📌 Project Methodology & Architecture

  • Dataset: ISOT Fake & Real News corpus (combining news headlines and body text).
  • Text Preprocessing: Lowercase transformation, URL removal, wire boilerplate scrubbing, punctuation/digit removal, and standard stopword filtering.
  • Feature Representation: Term Frequency-Inverse Document Frequency (TF-IDF) feature matrix learned strictly on training fold to prevent data leakage.
  • Classification Model: Regularized Logistic Regression (ElasticNet via R's glmnet) for high-accuracy binary classification.
  • Service API: R Plumber REST API exposing /health, /predict, and /metrics.
